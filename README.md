# D2 Study

第二種電気工事士の学科学習用Webアプリです。iPhone SafariとGitHub Pagesでの利用を主対象にしています。

基礎学習、オリジナル短問、公式過去問用50問マークシート、誤答復習、進捗保存、JSONバックアップを備えています。PWAとしてホーム画面へ追加でき、アプリ本体はService Workerでオフライン利用できます。公式過去問PDFは一般財団法人 電気技術者試験センターの外部PDFを参照するため、表示時には通信が必要です。

## GitHub Pages

`.github/workflows/deploy.yml` が `main` へのpush時にデプロイします。初回のみ、リポジトリの `Settings > Pages > Build and deployment > Source` を `GitHub Actions` に設定してください。

公開後はiPhoneのSafariでサイトを開き、共有メニューから「ホーム画面に追加」を選ぶとスタンドアロンWebアプリとして利用できます。

## データ保存

学習進捗はブラウザの `localStorage` に保存します。SafariのWebサイトデータを削除すると消える可能性があるため、アプリからJSONバックアップを書き出せます。
